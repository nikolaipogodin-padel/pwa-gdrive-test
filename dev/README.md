# Кошелёк — проверки и история правок (для разработчика)

Приложение — в `koshelek/`. Эта папка на работу приложения не влияет.

## tests/
Приёмочные проверки на Playwright (Chromium), только на вымышленных выписках; Google и Gemini заменены заглушками.

- `gen_data.py` — генератор вымышленных выписок (формат Swedbank LV CSV, упрощённый Revolut, пограничные файлы).
- `lib.js` — запуск браузера, перехват внешних адресов. Пути вида `/home/claude/audit/...` — рабочая папка сессии аудита, при переносе поправить.
- `gem_stub.js` — заглушка Gemini (режимы: ok, 429, 503, badkey, net, garbage через файл `/tmp/gem_mode`).
- `t_stage1.js` (26 проверок), `t_stage2.js` (13), `t_k44.js` (10), `t_stage3.js` (17) — запускать на чистых профилях.
- `t_stage3.js` и часть шагов требуют профиль с данными (`B_base`: первый запуск на `sw_main_2026-05_2026-10.csv`, подтверждён разбор).

Запуск: скопировать `koshelek/` в папку, `python3 -m http.server 8765` на уровень выше, затем
`NODE_PATH=$(npm root -g) node tests/t_stage1.js`.

## patches/
`kw_audit1.py … kw_audit6.py` — точечные замены сборок П15.3–П15.8 (история; повторно не применяются: каждая проверяет, что исходная строка встречается ровно один раз).

## При каждой сборке
Менять метку `BUILD` (platform.js) и `KW_INDEX_BUILD` (index.html) — одинаковые; имя кэша `koshelek-vN` в `sw.js`.
